ℹ️ How to use all buttons (click to expand)
  • పుస్తకం / అధ్యాయం — Select the book and chapter this quiz is about (used as the quiz title/reference).
  • ఖాళీ క్విజ్ ఫారం — Opens a blank form with 7 empty questions for you to write.
  • ✏️ సవరణ (edit Q&A) — In the form you can type or change the question and the three options directly; tap a row (or its ○) to mark it as the correct answer, and press 🗑 క్లియర్ to empty a single question. Your changes are kept when you press క్విజ్ ప్రారంభించండి, and you can come back to this form any time with మళ్లీ ఎడిట్ చేయండి.
  • వచనాల పరిధి (portion) — Pick a from and to verse so questions come only from that range. Leave "వరకు వచనం" empty to use the whole chapter from "నుండి". Press వచనాలు లోడ్ to fetch the chapter: if a range is already set it is kept and only that range is reported; your range is never overwritten.
  • 🤖 ఆటో ప్రశ్నలు — Auto-generates 7 questions from the selected portion only (or the full chapter if no portion is set), in two shapes: fill in the blank (the missing word or phrase is replaced inline by __________(డాస్)) and ఎవరు / ఎవరి questions. Each question has three options with the correct one ticked, plus an "Answer:" line. The question itself comes from the chosen verses, while the two wrong options are closely-matched words from the same book (same ending, similar length, same kind) so the three choices are genuinely hard to tell apart. Verse numbers are not shown. Common Telugu encoding errors in the source text are corrected automatically. Needs internet the first time a book is used (then it is cached).
  • Question / Options — Type the question and three options. Select the radio next to the correct answer.
  • క్విజ్ ప్రారంభించండి — Locks the form and switches to answer mode so you (or someone else) can take the quiz.
  • సమాధానాలు తనిఖీ చేయి — Checks answers and shows the score (green = correct, red = wrong).
  • 📄 Save as text — Downloads the quiz (with answers) as a .txt file.
  • 📚 Save to library — Saves the quiz in this browser, grouped by date.
  • 📂 Choose location & save — Pick a folder and save (or normal download if not supported).
  • మళ్లీ ఎడిట్ చేయండి — Returns to the blank/edit form so you can change questions.
  • కొత్త క్విజ్ — Clears everything and starts over with book/chapter selection.
  • Export all (library) — Exports every saved quiz into one text file.
  • 📄 Text / 📂 Save… / 🗑 — Download, save to folder, or delete a library item.
  • ⬇ Install app — Add to home screen on phones (iPhone: Share → Add to Home Screen).
