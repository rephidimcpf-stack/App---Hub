How to add more apps

  
Every app is its own HTML file. Because they open as separate pages, they never interfere with each other and the hub stays fast no matter how many you add.

  
    
    
  1. Put the new .html file in the same folder as index.html.
    2. 
    
  2. Tap Add app, type its name, file name and a short description, then save. It appears in the hub immediately.
    3. 
    
  3. To make it permanent for everyone, open the hub file and paste the generated line into the APPS = [ … ] list at the top of the script.
    4. 
  

  
Tip: keep each app's saved data (theme, records) under its own unique name so apps never overwrite each other's settings.
